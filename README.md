# Online Food Ordering System

## Introduction

The Online Food Ordering System is a web-based application that allows customers to view food items, select their preferred food, place orders, and manage their orders online.

## Features

- User registration
- User login
- View food menu
- Search food items
- Add food to cart
- Update food quantity
- Place food orders
- View order details
- Generate order confirmation

## Technologies Used

- HTML
- CSS
- JavaScript

## Installation

1. Download the project.
2. Open the project folder.
3. Open index.html in a web browser.

## Usage

1. Open the Online Food Ordering System.
2. Register or login to the system.
3. View the available food items.
4. Select the required food items.
5. Add the items to the cart.
6. Check the order details.
7. Place the order.
8. View the order confirmation.
